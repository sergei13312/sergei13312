# Telegram Daily Notes Bot

Простой Telegram-бот для заметок/ежедневника на Ubuntu.

## Возможности
- Добавление заметок с датой (по умолчанию — сегодня)
- Просмотр заметок за сегодня или за дату
- Просмотр всех заметок
- Удаление заметки по ID

## Требования
- Python 3.10+
- Токен Telegram-бота

## Установка
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск
```bash
export TELEGRAM_BOT_TOKEN="<ваш_токен>"
python3 bot.py
```

## Команды бота
- `/start` — помощь
- `/add <текст>` — добавить заметку на сегодня
- `/add <дата YYYY-MM-DD> <текст>` — добавить заметку на дату
- `/today` — заметки на сегодня
- `/date <YYYY-MM-DD>` — заметки на дату
- `/list` — все заметки
- `/delete <id>` — удалить заметку

## Примеры
```
/add купить молоко
/add 2025-01-15 позвонить врачу
/date 2025-01-15
/delete 3
```

База данных хранится в файле `notes.db` в текущей папке.
